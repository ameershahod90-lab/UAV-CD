# UAV-CD-APP — Project Bible

This directory contains the canonical rules and guidelines for all development
on this project.  **Every contributor — human or AI — must read and follow
these documents before making changes.**

## Document Index

| File | Scope | Purpose |
|---|---|---|
| [architecture.md](architecture.md) | Backend structure | Layers, module responsibilities, data flow |
| [code_style.md](code_style.md) | Python code style | Typing, naming, OOP, SOLID/DRY, patterns |
| [ui_ux.md](ui_ux.md) | Frontend / PyQt6 | Widget rules, theming, units, reactivity |
| [domain.md](domain.md) | Aerospace engineering | Reference textbooks, equation sources, methodology |
| [workflows/](workflows/) | Automated workflows | CI, testing, deployment steps |

## How To Use

1. **Before coding**, read the relevant bible file for the area you're touching.
2. **During review**, check changes against these rules.
3. **Update these files** when the project owner adds new guidelines.
